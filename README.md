# Сдвиг

Еженедельный выпуск для продуктовых и BI-аналитиков: AI-агенты, новые инструменты и практики. Выходит по понедельникам.

- `index.html`: страница (шаблон, стили, рендер).
- `issues.js`: данные всех выпусков, новый добавляется в начало.
- `EDITORIAL.md`: редакционный контекст и правила отбора.

Хостинг: GitHub Pages из ветки `main`, корень репозитория. Сборка не нужна.
Старые выпуски открываются по адресу `?issue=YYYY-MM-DD`.
